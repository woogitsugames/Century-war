# Century War — Google Play (UK)

## Title
Century War

## Short description
Стратегія крізь епохи: кампанія, облога та бої без інтернету.

## Full description

Веди армію крізь дев’ять епох. Наймай бійців, будуй вежі та вирішуй, коли перейти до наступної епохи.

Пройди 36 етапів кампанії з вибором складності, витримай хвилі нескінченної облоги або налаштуй власний бій. Погода, здібності, доктрини й дослідження відкривають тактичні можливості.

Переглядай повтори та графік після бою, відкривай прапори й зберігай профіль у файл. Налаштуй кольори та ввімкни режим для шульг. Кампанія та локальний прогрес працюють без інтернету.

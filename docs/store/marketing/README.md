# Materiały marketingowe Century War

- `slogany.md` — po pięć haseł na język, dwie rekomendacje oznaczone gwiazdką; długości UTF-16.
- `opis_sklepu.md` — alternatywne krótkie i pełne opisy, liczby znaków pod tekstem. Obecne karty i tytuły pozostają bez zmian; przed wklejeniem usuń linie z liczbami.
- `posty_testy.md` — krótkie i dłuższe zaproszenia do testów zamkniętych. Przed wysłaniem dodaj właściwy sposób dołączenia; nie wpisano niezweryfikowanego adresu.
- `posty_premiera.md` — trzy długości wpisów i hashtagi w każdym języku. Publikuj po rzeczywistym starcie.

Materiały nie są publikacją ani obietnicą daty. Przed użyciem sprawdź zgodność z ostatecznym wydaniem i konfiguracją, w tym działanie wersji testowej i nazwy funkcji. Wyzwania dzienne i tygodniowe mają własne warunki dostępności: nie obiecuj ich uruchomienia przed potwierdzeniem. Nie obiecuj gry dla niewidomych, funkcji sieciowych, nieograniczonej prywatności ani synchronizacji, których wydanie nie potwierdza. Raport dla testera gracz udostępnia samodzielnie; nie twierdź, że jest anonimowy lub wysyłany automatycznie. Przed publikacją zalecana jest redakcja native speakerów.

Walidacja: długości liczono jako jednostki UTF-16 (równoważne `len` dla użytych znaków bez par zastępczych). Limity haseł 40, krótkich opisów 80 i pełnych 4000. Kompilacja Gradle nie jest wymagana: dodano wyłącznie dokumenty marketingowe.
